# Word 문서 이미지 추출 및 분석 도구 사용법

## 📋 개요
게임기획 Word 문서에서 이미지를 자동으로 추출하고 분석하여 엑셀 파일로 정리하는 도구입니다.

## 🚀 설치 방법

### 1단계: Python 설치 확인
Windows PowerShell 또는 명령 프롬프트(CMD)를 열고 다음 명령어 입력:
```bash
python --version
```

Python이 설치되어 있지 않다면:
- https://www.python.org/downloads/ 에서 Python 다운로드 및 설치
- 설치 시 "Add Python to PATH" 옵션 체크!

### 2단계: 필요한 라이브러리 설치
명령 프롬프트 또는 PowerShell에서 다음 명령어 실행:
```bash
pip install pillow openpyxl python-docx
```

## 📝 사용 방법

### 방법 1: 스크립트 파일 다운로드 후 실행

1. `extract_images_from_word.py` 파일을 다운로드합니다

2. Word 문서가 있는 폴더에 스크립트 파일을 복사합니다

3. 명령 프롬프트에서 해당 폴더로 이동:
   ```bash
   cd "C:\Users\up_ma\OneDrive\바탕 화면\게임캔버스\1.기획이론\포트폴리오_구본일\원고작업"
   ```

4. 스크립트 실행:
   ```bash
   python extract_images_from_word.py
   ```

5. 프롬프트가 나타나면:
   - 엔터: 기본 파일 경로 사용
   - 또는 전체 파일 경로 입력

### 방법 2: 간편 실행 (배치 파일 사용)

`실행.bat` 파일을 더블클릭하면 자동 실행됩니다.

## 📊 결과물

실행이 완료되면 다음 파일들이 생성됩니다:

1. **이미지 폴더**: `[문서명]_이미지/`
   - Word 문서에서 추출된 모든 이미지가 저장됩니다

2. **엑셀 파일**: `[문서명]_이미지분석.xlsx`
   - 각 이미지의 상세 정보가 정리되어 있습니다
   - 포함 정보: 파일명, 크기, 포맷, 색상모드, 설명 등

## 🎯 엑셀 파일 내용

생성된 엑셀 파일에는 다음 정보가 포함됩니다:

| 번호 | 파일명 | 크기 | 포맷 | 색상모드 | 파일크기 | 설명 | 추가정보 | 경로 |
|------|--------|------|------|----------|----------|------|----------|------|
| 1 | image1.png | 800x600 | PNG | RGB | 125.5 KB | PNG 이미지... | 게임기획 문서 내 이미지 | ... |

## ⚠️ 주의사항

1. Word 문서는 `.docx` 형식이어야 합니다 (.doc는 지원 안 됨)
2. 파일 경로에 한글이 포함되어도 정상 작동합니다
3. 이미지가 없는 문서는 빈 결과를 반환합니다

## 🔧 문제 해결

### "모듈을 찾을 수 없습니다" 오류
```bash
pip install pillow openpyxl python-docx --upgrade
```

### "파일을 찾을 수 없습니다" 오류
- 파일 경로를 확인하세요
- 전체 경로를 복사해서 입력하세요
- 경로에 따옴표를 추가해보세요

### Python 명령어가 작동하지 않음
- Python이 제대로 설치되었는지 확인
- 환경 변수 PATH에 Python이 추가되어 있는지 확인
