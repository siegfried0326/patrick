📦 Word 이미지 추출 도구

📄 extract_images_from_word.py 메인
Word 문서에서 이미지를 추출하고 분석하여 엑셀 파일을 생성하는 메인 프로그램입니다.
⚡ 실행.bat 추천
더블클릭만 하면 자동으로 프로그램이 실행됩니다. 가장 쉬운 실행 방법!
🔧 라이브러리_설치.bat 필수
필요한 Python 라이브러리를 자동으로 설치합니다. 최초 1회만 실행하세요.
📖 README_사용법.md 도움말
상세한 사용 설명서와 문제 해결 방법이 포함되어 있습니다.

🚀 사용 방법 (3단계)

  1. 모든 파일 다운로드: 위의 "모든 파일 한번에 다운로드" 버튼 클릭
  2. 라이브러리 설치: "라이브러리_설치.bat" 파일을 더블클릭 (최초 1회만)
  3. 프로그램 실행: "실행.bat" 파일을 더블클릭하고 엔터만 누르면 완료!
