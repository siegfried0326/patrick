# Snake Game (뱀 게임)

클래식 Snake 게임을 웹 브라우저에서 즐길 수 있습니다!

## 게임 방법

1. `snake-game.html` 파일을 웹 브라우저에서 엽니다
2. "게임 시작" 버튼을 클릭하거나 방향키를 누르면 게임이 시작됩니다
3. 방향키(⬆️⬇️⬅️➡️)로 뱀을 조작합니다
4. 빨간색 음식을 먹으면 점수가 올라가고 뱀이 길어집니다
5. 벽이나 자신의 몸에 부딪히면 게임 오버!
6. 스페이스바를 눌러 다시 시작할 수 있습니다

## 기능

- 반응형 캔버스 기반 게임
- 점수 및 최고 점수 추적 (로컬 저장소에 저장)
- 부드러운 애니메이션과 그림자 효과
- 그리드 배경으로 더 쉬운 조작
- 키보드 컨트롤

## 조작법

- **방향키**: 뱀 이동
- **스페이스바**: 게임 재시작

## 실행 방법

웹 브라우저에서 `snake-game.html` 파일을 열기만 하면 됩니다. 추가 설치나 서버가 필요 없습니다!

## 최고 점수

최고 점수는 브라우저의 로컬 저장소에 자동으로 저장됩니다.

즐거운 게임 되세요! 🐍
